对 Pi 的含义

建议默认走家族 A（Codex）

产品壳已经是 Codex：用户气泡、助手散文、环境信息、变更卡。聊天默认也应「先给结论，工作折一行」。CSS 里已有 .work-log，但 Message.tsx 没用它，思考和工具被拆开常驻。

展开后走家族 B 的特化

用户点开「耗时 Xs ›」时，不要给 JSON。Read 显示路径和摘录，Edit 显示 diff，Shell 显示命令+输出，Search 显示命中。这是 Cursor / Claude Code / Cline 的共识。

  1. P0 恢复单行工作折叠 — 思考 + 工具默认合成「正在工作… / 耗时 Xs ›」，正文不被轨迹打断。
  2. P0 工具特化渲染 — 至少 Read / Edit / Shell / Grep / 网页搜索五类；展开禁止默认 JSON。
  3. P1 对话内变更卡 — Codex 的「已编辑 file +N −M」，点开才进 diff，而不是只在右栏。
  4. P1 密度三档 — 对齐 Claude Code：摘要 / 普通 / 详细。现有 summaryMode 可以接到 UI。
  5. P2 计划进对话 — 现在只在检查器。Cursor/Claude 把 Todo/Plan 放在时间线里。

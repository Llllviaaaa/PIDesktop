# @qianji/tool-guards

工具调用的两项保护，见 [ADR 0020](../../docs/adr/0020-tool-guards.md)。两项都挂在 `tools/execute` 上。

```ts
ctx.plugin(toolGuards, {});
```

| 字段 | 说明 |
|---|---|
| `defaultTimeoutMs` | 工具没有声明 `timeoutMs` 时的时限，默认 600000（10 分钟）；设为 0 关闭 |
| `repeatThresholds` | 连续重复到这些次数时附加提醒，默认 `[3, 5, 8]`；设为空数组关闭 |

- **时限**：一次调用最多运行工具声明的 `timeoutMs`。工具没有声明时用 `defaultTimeoutMs`；声明为 0 表示不限时，`bash` 和 `delegate_task` 就是这样。
  - 到时限后，这次调用的 `signal` 被中止，模型立即收到超时错误。工具不响应中止也不影响；它之后返回的结果会被丢弃。
  - 时限只作用于这一次调用；同一轮里并行的其他调用不受影响。
- **重复提醒**：同一个会话连续发出完全相同的调用（同一工具、同样的参数，参数里键的顺序不影响判断）时，在第 3、5、8 次的结果后附加一条提醒，说明结果不会变，让模型换个办法。最后一次提醒的措辞更强，要求它停下来，向用户说明卡在哪里。
  - 每个会话分开计数，发出别的调用后重新计数。
  - 内存里最多记 500 个会话，最久没有活动的先被遗忘。
